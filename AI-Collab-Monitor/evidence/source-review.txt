# AI-Collab-Monitor v0.1

本次實機驗收與原始文字證據請見 [驗收紀錄](evidence/ACCEPTANCE-REPORT.md)。

這是放在桌面的三 Agent 監看器。它在單一 Windows Terminal 視窗中，即時顯示 Claude、dot、Codex 與協作時間線的文字 log。v0.1 只是 **observability layer（可觀測性層）**：讀取已寫入的紀錄，協助人工追蹤輸入、輸出、公開摘要、審查、handoff、命令、diff 與測試結果。

Monitor 不會啟動、控制或協調 Agent，不會派工、批准執行、觸發下一步或建立 orchestrator。它不會自動抓取 Agent 對話、其他 Terminal 畫面、設定或憑證，也不會擷取任何 Agent 的隱藏 chain-of-thought。`REASONING SUMMARY` 只供 Agent 主動提供的公開推理摘要與 decision rationale 使用。

## 啟動

使用一般使用者權限，雙擊 `AI-Collab-Monitor.bat`。也可在本目錄的 PowerShell 執行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-monitor.ps1
```

腳本先確認 `wt.exe` 與四個 log；只安全補建不存在的 log，不清空既有內容。接著開啟單一 Windows Terminal 視窗與四格監看。重複啟動同一套監看器會被阻擋，並以非零結束碼回報；不會再開一組監看。

每格使用 Windows 原生 .NET 檔案讀取方式，以約 200 毫秒的輪詢週期等待新內容，並同時檢查停止訊號。不需要 Node、Electron、Tauri、Web server 或系統管理員權限。`ExecutionPolicy Bypass` 只適用該次 PowerShell 子程序，不修改系統或使用者的永久 ExecutionPolicy。

## 停止

在本目錄執行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\stop-monitor.ps1
```

每次啟動使用新的 GUID session。每格監看程序在存活期間持有自己的獨占 lease；停止腳本向本套監看器的 session 寫入 `stop.signal`，由各格自行結束，並阻止該 session 尚未完成的延遲啟動。生命週期 gate 用來避免啟動、停止、reset 的競爭。

停止不依賴 PID 強制終止，不會執行 `taskkill`，也不會關閉其他 PowerShell、Windows Terminal、Claude 或 Codex 工作階段。若 Terminal 的使用者設定保留已結束的 pane，確認監看已停止後，手動關閉這個 Monitor 視窗即可。若腳本不能安全確認狀態，依它顯示的提示手動關閉這個 Monitor 視窗；不要批次終止程序。不要手動刪除 `.monitor` 或其中的 session 檔案來略過安全檢查。

若直接手動關閉 Monitor 視窗，session 仍會保守地視為運作中或待啟動。**重新啟動或 reset 前，仍須執行一次 `stop-monitor.ps1`**，讓該 session 收到停止訊號，也阻止可能延遲出現的 pane 啟動。

## Reset 與封存

先暫停所有會寫入這四個 log 的外部來源，再停止 Monitor；確認監看已結束後，在本目錄執行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\reset-monitor.ps1
```

reset 會先檢查監看狀態；仍在監看或仍有待完成的啟動時，會拒絕執行並提示安全操作方式，不會在背景偷偷替換 log。

安全狀態下，reset 會：

1. 建立 `archive\YYYYMMDD-HHmmss\`；名稱碰撞時使用唯一後綴，保留既有封存。
2. 將目前的四個 log 移入該封存目錄。
3. 在 `logs\` 建立新的四個空 log。

reset 不會刪除 `tasks\`、既有 `archive\`、README 或腳本。完成後可重新啟動 Monitor，再恢復外部寫入。它只能掌握自己的監看程序，不能替任何外部 writer 暫停或協調 log rotation；若 writer 在 reset 期間持續寫入，可能發生檔案占用或資料落到封存檔，因此暫停 writer 是操作前提。

## 如何寫入 log

四個 log 初始為空檔。v0.1 不會自動從 Agent 收集資料；只有實際寫入檔案的內容才會出現在 pane。請以 **UTF-8、附加寫入、每筆以換行結尾** 的方式記錄，避免在監看期間覆寫、截短、刪除或替換檔案。監看器逐批顯示新讀到的文字，不必等到整行完成；跨批次的 UTF-8 字元會保留解碼狀態。

以下是可在 Windows PowerShell 5.1 使用的手動測試；請在 Monitor 根目錄執行。這些文字只是測試，不代表真實 Agent 的審查或執行結果：

```powershell
$monitorRoot = (Get-Location).Path
$utf8 = [Text.UTF8Encoding]::new($false)
[IO.File]::AppendAllText((Join-Path $monitorRoot 'logs\claude.log'), "[TEST DATA] Claude pane test`r`n", $utf8)
[IO.File]::AppendAllText((Join-Path $monitorRoot 'logs\dot.log'), "[TEST DATA] Dot pane test`r`n", $utf8)
```

Set-StrictMode -Version Latest
$ErrorActionPreference = 'Stop'
$script:MonitorRoot = [IO.Path]::GetFullPath((Split-Path -Parent $PSScriptRoot))
$script:MonitorActors = @('claude', 'dot', 'codex', 'timeline')
$script:MonitorState = Join-Path $script:MonitorRoot '.monitor'

function Assert-MonitorPath([string]$Path) {
    $full = [IO.Path]::GetFullPath($Path)
    if ($full -ne $script:MonitorRoot -and -not $full.StartsWith($script:MonitorRoot + '\', [StringComparison]::OrdinalIgnoreCase)) {
        throw "Path is outside this monitor: $full"
    }
    $cursor = $full
    while ($cursor.Length -ge $script:MonitorRoot.Length) {
        if (Test-Path -LiteralPath $cursor) {
            if ((Get-Item -LiteralPath $cursor -Force).Attributes -band [IO.FileAttributes]::ReparsePoint) {
                throw "Refusing linked/reparse monitor path: $cursor"
            }
        }
        if ($cursor -eq $script:MonitorRoot) { break }
        $cursor = Split-Path -Parent $cursor
    }
    return $full
}

function New-MonitorDirectory([string]$Path) {
    $full = Assert-MonitorPath $Path
    [void][IO.Directory]::CreateDirectory($full)
}

function New-MonitorEmptyFile([string]$Path) {
    $full = Assert-MonitorPath $Path
    if (Test-Path -LiteralPath $full) {
        if (-not [IO.File]::Exists($full)) { throw "Expected a file: $full" }
        return
    }
    $file = [IO.File]::Open($full, [IO.FileMode]::CreateNew, [IO.FileAccess]::Write, [IO.FileShare]::Read)
    $file.Dispose()
}

function Enter-MonitorGate {
    New-MonitorDirectory $script:MonitorState
    $path = Assert-MonitorPath (Join-Path $script:MonitorState 'lifecycle.lock')
    $deadline = [DateTime]::UtcNow.AddSeconds(5)
    while ($true) {
        try { return [IO.File]::Open($path, [IO.FileMode]::OpenOrCreate, [IO.FileAccess]::ReadWrite, [IO.FileShare]::None) }
        catch [IO.IOException] {
            if ([DateTime]::UtcNow -ge $deadline) { throw 'Another monitor lifecycle operation is running. Try again after it finishes.' }
            Start-Sleep -Milliseconds 100
        }
    }
}

function Get-MonitorSessions {
    $dir = Assert-MonitorPath (Join-Path $script:MonitorState 'sessions')
    if (-not (Test-Path -LiteralPath $dir)) { return }
    foreach ($item in Get-ChildItem -LiteralPath $dir -Directory) {
        if ($item.Name -notmatch '^[a-f0-9]{32}$') { throw "Unrecognized session directory; inspect manually: $($item.FullName)" }
        [void](Assert-MonitorPath $item.FullName)
        $item.FullName
    }
}

function Test-MonitorLeaseBusy([string]$SessionPath, [string]$Actor) {
    $leasePath = Assert-MonitorPath (Join-Path $SessionPath ($Actor + '.lease'))
    if (-not (Test-Path -LiteralPath $leasePath)) { return $false }
    try {
        $probe = [IO.File]::Open($leasePath, [IO.FileMode]::Open, [IO.FileAccess]::ReadWrite, [IO.FileShare]::None)
        $probe.Dispose()
        return $false
    }
    catch [IO.IOException] { return $true }
    # Permission/unknown errors are deliberately not treated as an inactive lease.
}

function Get-MonitorBlockers {
    foreach ($session in @(Get-MonitorSessions)) {
        if (-not (Test-Path -LiteralPath (Assert-MonitorPath (Join-Path $session 'stop.signal')))) {
            "Session $(Split-Path -Leaf $session) is running or pending."
        }
        foreach ($actor in $script:MonitorActors) {
            if (Test-MonitorLeaseBusy $session $actor) { "Active lease: $(Split-Path -Leaf $session)/$actor" }
        }
    }
}

function Request-MonitorStop([string]$SessionPath) {
    New-MonitorEmptyFile (Join-Path $SessionPath 'stop.signal')
}

function Write-MonitorJson([string]$Path, $Value) {
    $full = Assert-MonitorPath $Path
    [IO.File]::WriteAllText($full, ($Value | ConvertTo-Json -Depth 6), [Text.UTF8Encoding]::new($false))
}

function Quote-MonitorArgument([string]$Value) {
    # Values are our fixed flags/titles/IDs or validated absolute paths, never a shell expression.
    if ($Value -match '["\r\n]' -or $Value.EndsWith('\')) { throw 'Unsupported character/trailing separator in command argument.' }
    return '"' + $Value + '"'
}

param(
    [Parameter(Mandatory=$true)][ValidatePattern('^[a-f0-9]{32}$')][string]$SessionId,
    [Parameter(Mandatory=$true)][ValidateSet('claude','dot','codex','timeline')][string]$Actor
)
. (Join-Path $PSScriptRoot 'common.ps1')
$titles = @{
    claude = 'CLAUDE - PRIMARY REVIEWER'
    dot = 'DOT - SECONDARY REVIEW / RELAY'
    codex = 'CODEX - IMPLEMENTER'
    timeline = 'COLLABORATION TIMELINE'
}
$colors = @{ claude = 'Cyan'; dot = 'Yellow'; codex = 'Green'; timeline = 'Magenta' }
$sessionPath = Assert-MonitorPath (Join-Path (Join-Path $script:MonitorState 'sessions') $SessionId)
$logPath = Assert-MonitorPath (Join-Path (Join-Path $script:MonitorRoot 'logs') ($Actor + '.log'))
$stopPath = Join-Path $sessionPath 'stop.signal'
$gate = $null
$lease = $null
$logStream = $null
$exitCode = 0
try {
    $gate = Enter-MonitorGate
    # Stop/reset can happen while Terminal is still launching a delayed pane.
    if (-not (Test-Path -LiteralPath (Join-Path $sessionPath 'session.json')) -or (Test-Path -LiteralPath $stopPath)) { return }
    $lease = [IO.File]::Open((Assert-MonitorPath (Join-Path $sessionPath ($Actor + '.lease'))), [IO.FileMode]::OpenOrCreate, [IO.FileAccess]::ReadWrite, [IO.FileShare]::None)
    # No Delete sharing: even an outside rename cannot silently strand the tail.
    $logStream = [IO.File]::Open($logPath, [IO.FileMode]::Open, [IO.FileAccess]::Read, [IO.FileShare]::ReadWrite)
    Write-MonitorJson (Join-Path $sessionPath ($Actor + '.started.json')) ([ordered]@{
        Actor=$Actor; Pid=$PID; StartedUtc=[DateTime]::UtcNow.ToString('o'); Log=$logPath; SessionId=$SessionId
    })
    $gate.Dispose()
    $gate = $null
    [Console]::OutputEncoding = [Text.UTF8Encoding]::new($false)
    $Host.UI.RawUI.WindowTitle = 'AI-Collab-Monitor | ' + $titles[$Actor]
    Write-Host $titles[$Actor] -ForegroundColor $colors[$Actor]
    Write-Host ('logs\' + $Actor + '.log  |  v0.1  |  read only') -ForegroundColor DarkGray
    Write-Host ('=' * 42) -ForegroundColor DarkGray
    # Native .NET incremental UTF-8 reader. It can stop even when no lines arrive.
    # Decoder retains partial multibyte characters across separate appends.
    $encoding = [Text.UTF8Encoding]::new($false, $false)
    $decoder = $encoding.GetDecoder()
    $bytes = New-Object byte[] 8192
    $chars = New-Object char[] ($encoding.GetMaxCharCount($bytes.Length))
    while (-not (Test-Path -LiteralPath $stopPath)) {
        $count = $logStream.Read($bytes, 0, $bytes.Length)
        if ($count -gt 0) {
            $length = $decoder.GetChars($bytes, 0, $count, $chars, 0, $false)
            $text = [string]::new($chars, 0, $length)
            # Logs remain unchanged. Strip terminal control characters from display.
            $text = [regex]::Replace($text, '[\x00-\x08\x0B\x0C\x0E-\x1F\x7F-\x9F\uFEFF]', '')
            [Console]::Write($text)

            Start-Sleep -Milliseconds 200
        }
    }
    Write-Host "`n[MONITOR STOPPED]" -ForegroundColor DarkGray
} catch {

    Write-Host ('[MONITOR ERROR] ' + $_.Exception.Message) -ForegroundColor Red
} finally {
    if ($logStream) { $logStream.Dispose() }
    if ($lease) { $lease.Dispose() }
    if ($gate) { $gate.Dispose() }
}
exit $exitCode
